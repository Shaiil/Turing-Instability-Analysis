# Turing Instability Analysis - Exploring Morphogenesis

The project involves the mathematical stability analysis and numerical simulations for exploring **Turing Pattern Formation (Diffusion-Driven Instability)** in reaction-diffusion systems, with a dedicated application to the **Gray-Scott Model**.

Morphogenesis is the biological process through which homogeneous cells and tissues acquire form and structure. In 1952, Alan Turing proposed a counterintuitive mechanism: **a system stable in the absence of diffusion can become unstable when diffusion is introduced**, giving rise to spatial patterns (like jaguar spots or zebra stripes). This project explores the stability analysis of Turing conditions for reaction-diffusion systems through rigorous proofs focusing on the Gray-Scott model.

We use numerical solvers and implement a numerical simulation to observe the evolution of the system under the given conditions and prove Turing instability in case of diffusion. Simulated videos of prominent patterns can be found in the 'Graphs and Visualizations' folder.
